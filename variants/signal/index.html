Keep the stable parts of config plain.

Kimen is a local-first secrets tool. It stores secrets in an encrypted local vault and lets you project them into runtime only when you explicitly ask. Stable settings can live in a normal file or template. Sensitive fields can stay in the vault until Kimen prepares the runtime environment for the app.

Local Vault

Secret values are stored locally and kept encrypted until you choose to project them.

Static Config

Plain values do not need special treatment. The interesting part is filling the sensitive slots only when a process needs them.

Application

The app can stay boring. It still reads env the way it always has, because Kimen prepares it up front.

App stays simple

Typical reader inside the application:

apiToken := os.Getenv("API_TOKEN")
