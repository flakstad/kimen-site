Vault

Keep the secret encrypted on disk until you actually need it.

Intent

Name the env var or file and choose which command gets it.

Run

The target process gets the value. The rest of the shell does not.

Kimen is an open source command-line tool for local secrets. It stores them in an encrypted vault, then projects one into the environment or files of a command when you ask for it. 

$ kimen render --dir "$OUTDIR" --file service-api-token.txt=demo_service_api_token
