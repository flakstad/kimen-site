Kimen prepares secrets before the app starts.

Kimen is a local-first secrets tool. Kimen stores secrets in an encrypted local vault and lets you project them into runtime only when you explicitly ask. The app itself can stay simple. If Kimen prepares env or files up front, the application can keep reading its normal config inputs.

What it solves

Secret storage is only half the problem. Kimen also narrows the runtime handoff, so you do not need to leave values in global shell state or commit them into static files.

What stays plain

Non-secret config can stay where it already lives. Kimen only needs to supply the sensitive fields.

What the app sees

Regular env vars or file paths. Kimen does not require the application to adopt a custom secrets API.

Example: render a file when a tool wants a path instead of an env var. 

$ kimen render --dir "$OUTDIR" --file tls/cert.pem=demo_tls_cert_path
