Runtime lanes

Most vaults answer where a secret sleeps. Kimen answers how it wakes up.

Keep the value in a local vault. Choose a shape. Name the target. Project it into one process lane instead of making it part of every shell, every command, and every assistant session.

Projection grammar

Vault. Intent. Shape. Target.

Vault

Encrypted local storage is the resting state.

Intent

The user or automation run asks for projection.

Shape

Env var, file, envfile, or direct child process input.

Target

The named process gets it. Others do not.

Command lines

Direct use.

$ kimen run \
  --env SERVICE_API_TOKEN=demo_service_api_token \
  -- sh -lc 'echo "Token length: ${#SERVICE_API_TOKEN}"'
$ OUTDIR="$(mktemp -d -t kimen-render.XXXXXX)"
$ kimen render --dir "$OUTDIR" \
  --file service-api-token.txt=demo_service_api_token
$ kimen run \
  --env PROVIDER_API_KEY=assistant_key \
  -- codex
