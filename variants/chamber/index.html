Prepare env before the process starts.

Kimen is a local-first secrets tool. Kimen stores secrets in an encrypted local vault and lets you project them into runtime only when you explicitly ask. The application can stay simple and read config or secrets from env directly, as long as Kimen prepares the runtime inputs first.

Vault Entry

assistant_key

Prepared Input

API_TOKEN

App Reads

process.env.API_TOKEN

One possible Kimen command:

$ kimen run --env API_TOKEN=assistant_key -- myapp

Meaning:

Prepare one env var for the process being started.
