Kimen is a local-first secrets tool. It stores secrets in an encrypted local vault and lets you project them into runtime only when you explicitly ask.

Pick one secret, trace it through the config sheet, and watch it land as a standard environment variable. The app does not need special secret-handling logic if something prepares the env before it starts.

Vault Entry

assistant_key

Target Env

API_TOKEN

App Side

Reads env directly. No custom secret client inside the app.

One possible Kimen command:

$ kimen run --env API_TOKEN=assistant_key -- myapp

What the application code still looks like:

process.env.API_TOKEN
