Vault object

Stored closed. Opened on intent.

Kimen is a local-first vault for secrets and config material. Its differentiator is not storage alone. Its differentiator is how values enter runtime: explicitly, narrowly, and only for the target process.

No required account.
No browser-first control surface.
No mandatory hosted backend in the hot path.
vault / local / encrypted projection / env / file / envfile target / named / process

Before Kimen Values drift into shell state, copied files, and tools that did not need them.

With Kimen The vault is the resting state. Projection is an explicit event.

What stays true Once a process gets a secret, that process has it. Kimen narrows the path up to that point. 

$ kimen run \
  --env SERVICE_API_TOKEN=demo_service_api_token \
  -- ./your-command
$ kimen render \
  --dir "$OUTDIR" \
  --file service-api-token.txt=demo_service_api_token
$ kimen run \
  --env PROVIDER_API_KEY=assistant_key \
  -- codex
