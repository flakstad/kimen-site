Kimen keeps the vault local and the app ordinary.

Kimen is a local-first secrets tool. Kimen stores secrets in an encrypted local vault and lets you project them into runtime only when you explicitly ask. Stable config can stay plain. Kimen prepares env or files before the process starts, so the application can keep reading normal configuration inputs.

The important thing is the projection step. Many tools solve only storage. Kimen also solves the handoff into runtime. That is where secrets often spread into copied files, shell history, global exports, or tools that did not need them.

Example 
$ kimen run --env API_TOKEN=assistant_key -- myapp
Storage

Secrets stay in an encrypted local vault until projection time.

Projection

Kimen can prepare env vars or files for the process being started.

Application

The app can keep reading `process.env` or a normal file path.
