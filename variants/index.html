Kimen / local CLI for encrypted secrets

Kimen is a local-first secrets tool. Kimen stores secrets in an encrypted local vault and lets you project them into runtime only when you explicitly ask.

That means apps can stay simple and read config and secrets from env directly, as long as something prepares the env up front. These variants all explore that model.

01 Conduit A direct explanation of Kimen as a runtime pipe from vault to config to env to app. 02 Sheet A paper-first page that explains how static config and secret fields live together. 03 Relay An interactive mapping from one vault entry to the env var the app reads.
