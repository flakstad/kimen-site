Secrets don't belong in the project your agent can read.

Your app still needs database passwords, API keys and service credentials. Kimen keeps them in a local encrypted vault and supplies them only when they are used.

.gitignore protects secrets from Git. Not from your agent.

If a secret is a file in the working tree, a coding agent with file access can read it.

The secret is beside the code

An .env, private key or service-account file contains the real value.

Move the values out. Leave a readable map behind.

Kimen is a small local vault plus a step that prepares the environment immediately before your app starts.

Let the agent deploy. Keep the deploy credential.

Moving a credential to another vault is not enough if the agent can fetch it. Kimen uses the credential itself, performs one permitted action and returns only the result.

The operation, target and accepted inputs are defined outside the repository. The agent can request the action. It cannot redefine it or gain the broader access behind it.

Give agents the smallest useful action.

Kimen holds the broad credential and exposes a narrow, predefined operation.

Deploy one revision to staging

Fix the environment and limit the request to the revision the agent completed.

Trigger a server-side backup

Back up one known database without sharing the provider's API credential.

Restart a known service

Expose the predefined restart, not SSH access or arbitrary server commands.
