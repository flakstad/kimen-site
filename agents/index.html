Give agents the operation. Not the credential.

Let a coding agent deploy one commit to staging, inspect logs for one service or restart one known worker—without giving it a token that can do far more.

The code is finished. The agent stops where authority begins.

A general-purpose credential often grants access to an entire API, account or infrastructure environment. The task usually needs one much smaller effect.

Give the process a credential

The process can use every permission attached to that token.

  • Credential enters the execution environment
  • Caller may choose other API operations
  • Blast radius follows the token's scope

Give the agent an operation

Kimen performs one locally bound operation and returns its result.

  • Credential remains behind the boundary
  • Target and input are constrained
  • Every invocation produces a receipt

The project names the need. The environment defines the power behind it.
