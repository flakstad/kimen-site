Local secrets for the programs you run

Secrets belong to your environment.
Not your project.

Kimen keeps passwords and API keys in an encrypted local vault, then passes them to your application when you run it.

brew install flakstad/kimen/kimenHomebrew

Native CLI · works offline · MIT licensed

One practical change

Remove the .env file from the workspace.

In the project today

DATABASE_URL=postgres://…
STRIPE_KEY=sk_live_…

Plaintext sits beside the code, where tools and coding agents can find it.

→

With Kimen

env DATABASE_URL=secret:database_url
env STRIPE_KEY=secret:stripe_key

The project keeps readable requirements. The values stay in your local vault.

Then run the program normally.

$ kimen run --profile dev -- ./your-app

Your application receives ordinary environment variables. It does not need a Kimen library or SDK.
