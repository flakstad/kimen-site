Let coding agents do the work. Keep credentials under your control.

Kimen gives a project a way to state what it needs while values and permissions remain local. A trusted program can receive a secret. An agent can be allowed to perform a specific operation without receiving the underlying credential.

The local binding is the authority.

A repository may request a secret or operation. Editing that request cannot create a credential, change the deployment target or replace an approved operation with arbitrary code.

Projection and controlled operations have different boundaries. A program receiving a projected secret can read it. An agent invoking an operation should receive only its result.

Product status. Vault, profiles and runtime projection form the current open-source core. Agent identity, approval, constrained operations and receipts are the commercial direction under test.
