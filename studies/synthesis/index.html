Why now

Give the agent broad room to work without making credentials ambient.

Coding agents are useful because they can read the repository, edit files and run tools. That does not mean passwords, cloud credentials and deploy keys need to sit in the same workspace.

The product boundary

The project may request authority. It cannot define or enlarge it.

The local binding fixes the provider operation, destination and permitted inputs. The repository cannot replace an approved action with a script it controls.

Grants are tied to a caller and time window. Actions keep the underlying credential inside Kimen's trusted adapter and produce an execution receipt.

Projection remains an explicit trust decision: when a process receives a secret, that process is inside the boundary and can read the value.

Product statusThe encrypted vault, declarative profiles and runtime projection form the existing open-source core. Caller controls, grants, receipts and constrained Actions shown here are the product direction under test.
