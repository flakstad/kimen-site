A coding agent can read the names and mappings in your .kmap without finding plaintext values in that file. The trusted runtime receives the actual values when you invoke Kimen.

A precise boundary.

Keeping secrets outside the workspace reduces everyday exposure. It does not isolate them from an unrestricted agent running as your user. Locking a session prevents reuse of that session; it does not revoke credentials already passed to a process.
