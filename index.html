Secrets don't belong in the project your agent can read.

Your application still needs database passwords, API keys and service credentials. Kimen keeps the values in a local encrypted vault, outside the workspace, and supplies them only when a runtime needs them.

One project map. More than one kind of runtime.

Kimen is not tied to deployment. It prepares values for the local application, a test, a build tool, a one-off command or a runtime file.

Run an application

kimen run --profile dev -- ./app

Run a test suite

kimen run --profile test -- ./test

Render a required file

kimen render --dir ./runtime --profile staging

Prepare an envfile

kimen envfile --out .env.runtime --profile worker

The selected process receives projected values. Use kimen run for software you trust with those values—not as a sandbox for arbitrary code.

Sometimes the agent needs an outcome, not the credential behind it.

Starting your application is one case. Deploying staging, reading scoped logs or restarting a known service is different: the agent should be able to request the operation without receiving a general GitHub, cloud or infrastructure credential.
